## Research

Written before and during the build. They are kept as they were written, apart from small path fixes, so they also record how the thinking changed.

- [Dog vision catalog](research/catalog.md): normal dog vision, breed and age, 30+ eye conditions, with numbers, sources, confidence levels and shader recipes. Start with the Synthesis (§S1–S6).
- [Realism audit](research/realism-audit.md): the measured audit of the "Senior, 15" presets that found them about 4× too blurry, and the fixes. [Renders](research/realism-audit/) from before and after.
- [Tech stack](research/tech-stack.md): library and rendering choices (WebGL2, pyramid blur, later ML for eye photos), with licences.

Each document has its own reference list and uses the same confidence labels: **Established**, **Probable**, **Speculative**.
