# Realism audit files

Working files from the [realism audit](../realism-audit.md).

- `probe.js` and `analyze.py`: the first version of the grating and glare probes. The maintained versions are [`tests/probe.js`](../../../tests/probe.js) and [`tests/realism.py`](../../../tests/realism.py).
- `*.jpg`: renders of the procedural scenes. `*-current` is the build the audit measured (commit `66d8de8`, about 4× too blurry); `*-proposed` is the audit's mock-up, whose values shipped in commit `e574629`; `street-adultdog` is the adult control.
